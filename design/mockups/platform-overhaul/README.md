# Relay platform system mockups

This board rebuilds the chosen Relay direction as one complete, restrained
product system. It removes gradients, decorative geometry, neon colors, and
oversized dashboard compositions.

## Product structure

- **Client workspaces:** the admin lands on a simple card grid and can open or
  add a client.
- **Admin home:** bot health, questions, helpfulness, and actionable signals in
  one scan.
- **Client home:** only the bot, learning, and enabled results are visible.
- **Bot:** independent client branding, conversation settings, and a live
  preview.
- **Learning:** a focused library for files, answers, pages, and collections.
- **Analytics:** restrained metrics, trends, topics, and answer quality.
- **Signals:** admin-only patterns with explicit client visibility.
- **Settings:** client navigation, workspace identity, appearance, and access.
- **New client:** a short, progressive setup flow.
- **Landing page:** the same type, color, spacing, and product language as the
  signed-in platform.

## Design rules

- Neutral surfaces and one blue action color.
- Solid cards with subtle borders; no gradients or ornamental shapes.
- One primary action per page.
- Status colors only communicate status.
- Contrast-safe avatar colors with white initials.
- Light and dark mode share the same hierarchy.
- SF system typography and an 8px spacing rhythm.

Open `index.html` and use the top strip to review every screen and appearance.
